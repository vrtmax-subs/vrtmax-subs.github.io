Community-made Firefox extension

English subtitles for VRT MAX.

Watch supported VRT MAX episodes with community-maintained English subtitles, loaded automatically in the existing player.

Add to Firefox View source

Requires Firefox 140 or newer on desktop, or Firefox 142 or newer on Android.

01

Open an episode

Sign in to VRT MAX normally and start a supported episode. VRT remains responsible for playback, accounts, ads, DRM, and location checks.

02

Subtitles load

The extension requests the matching English subtitle file from the public community repository and adds it to the VRT player.

03

You stay in control

Use the EN subtitles control on the page to check availability or hide subtitles for that episode.

This is an independent community project. It is not affiliated with or endorsed by VRT.
