Community-made browser extension

English subtitles for VRT MAX.

Watch VRT MAX episodes with community-maintained English subtitles, loaded automatically in the existing player.

Add to Firefox Add to Chrome

Requires Firefox or Chrome.

How it works

01

Install

Install the extension in your browser (Firefox or Chrome).

02

Open an episode

Sign in to VRT MAX as usual and play a supported episode.

03

Subtitles load

The extension automatically requests the English subtitles and adds it to the VRT player.

This is an independent community project. It is not affiliated with or endorsed by VRT.
